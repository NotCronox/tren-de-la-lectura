# El tren de la lectura

Presentación interactiva para Producción Textual: análisis del artículo «Análisis de la integración de ChatGPT en el aprendizaje universitario con apoyo de blogs» (Zúñiga Zárate, *Comunicar* n.º 80, 2025).

**Autores:** Camilo Andrés López González · Linda Valentina Palacio Chamorro · Vladimir Gómez Páez

**Ver en línea:**
- Versión resumida (9 láminas, con guion en las notas): https://notcronox.github.io/tren-de-la-lectura/
- Versión completa (23 láminas): https://notcronox.github.io/tren-de-la-lectura/completa.html

Cada versión es un solo archivo (`index.html` = resumida y `completa.html` = completa) que funciona sin internet: incluye el tren bala en 3D (three.js, licencia MIT) y las fuentes (licencia SIL OFL).

## Controles
- Clic o → : avanzar · ← : retroceder · un clic durante una cinemática la salta
- Toca los elementos con el punto ámbar para interactuar
- **F** pantalla completa · **N** notas del orador · **M** sonido · **P** pausar el 3D · **E** modo edición
